# Шифрование

Основная концепция:

- Данные сохраняются на диске в профиль пользователя в зашифрованном виде.
- Ключ шифрования хранится в виде файла в профиле в зашифрованном виде.
- Пин-код хранится в виде файла в профиле в зашифрованном виде.
- Шифрование ключа и пин-кода выполняется с помощью системного ключа шифрования.

Необходимо учесть обратную совместимость. Старый ключ может быть сохранён в keytar. В этом случае нужно достать ключ, перешифровать, сохранить на диск и удалить его из keytar.

В случае отсутствия поддержки шифрования в ОС функции шифрования становятся недоступны. Невозможно включить доступ по ПИН-коду. Отображатеся предупреждение что данные хранятся в открытом виде.

### Резервное копирование

- Возможно выполнить резервное копирование данных в открытом виде.
